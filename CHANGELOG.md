# Changelog

## 0.1.0a1 — Initial environmental-only public source candidate

- New independent source tree and history for postcode environmental research.
- Real-data import with restricted output schema and source checksums.
- Complete-year 2022–2025 air-pollution aggregation and optional local GeoTIFF samples.
- Explicit non-equal environmental MCDA weights and two-criterion Monte Carlo preference sensitivity.
- Global competition ranks, tie-inclusive top group, preserved unscored postcodes.
- Country-qualified postcode lookup, guarded report refresh, HTML/JSON/CSV output.
- Clearly labelled synthetic demonstration and automated tests.
- No bundled provider data, no scientific production/clinical validation claim.
