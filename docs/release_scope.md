# Scope and readiness of the initial public edition

This repository is a **new environmental-only source package**. It is deliberately narrower than a complete environmental-health observatory or a production epidemiological tool. It provides local postcode observations, air-pollution summaries, transparent analyst-selected scoring, simple sampled preference sensitivity and postcode reports.

It currently supports local GeoTIFF point samples and an explicit set of environmental descriptors. It does not yet include an automated validated EU-wide provider-download workflow, native strategic-noise processing, complete environmental light/heat/industrial/pollen pipelines, reviewed weighting of every proposed domain, population weighting, or scientific production certification. These omissions are recorded rather than filled with invented values.

The current public implementation is a cleanly scoped alpha edition, **not a feature-for-feature port** of a private, differently scoped development checkout. Do not assume its input formats, numerical output or all commands are interchangeable with earlier experiments unless explicitly verified.

Use it for reproducible, source-documented exploratory environmental comparisons. For an operational recruitment or public-health decision, first arrange independent scientific review, documented data support, reference-population fairness checks, missingness sensitivity and source/licence approval.
