# Security and reporting

Please do not submit secrets, access tokens, confidential participant information, private research attachments, or large copyrighted provider datasets in public GitHub issues or pull requests.

Input CSVs and local raster files are untrusted until checked. This alpha edition validates required columns, numeric bounds, duplicate keys, nonfinite values and explicit output directories. Do not use it as a hosted multitenant service or run it on untrusted private files without suitable process isolation.

For a security problem, use a private GitHub security advisory if the repository has enabled that feature; otherwise contact a repository maintainer through an appropriate nonpublic channel. Please include the affected version and a safe reproduction case.
